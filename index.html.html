Ringkasan

Website ini adalah blueprint sederhana untuk lab cybersecurity gratis: daftar latihan, template dokumentasi, dan petunjuk cepat untuk menyiapkan VM/containern secara lokal atau di cloud gratis.

Gunakan untuk: workshop, bootcamp, portofolio, demonstrasi SIEM, atau bahan latihan CTF internal.

Modul Lab (Contoh)

1. Network / Traffic Analysis

Objective: Tangkap & analisa lalu lintas (pcap). Tools: Wireshark, Zeek, tcpdump.

  • Exercise: identifikasi beban C2 sederhana di pcap.
  • Output: laporan singkat + pcap teranotasi.

2. Malware Analysis (Static)

Objective: analisa sampel (hash, strings, imports). Tools: strings, PEStudio.

  • Exercise: catat indikator IOCs dan buat summary.

3. SIEM & Log Analysis

Objective: konfigurasi ELK/ Wazuh / OSSIM ringan untuk korelasi alert.

  • Exercise: ingest log web + buat rule deteksi brute force.

4. Forensic Disk / Memory

Objective: image disk, analisa artefak, timeline.

  • Exercise: ekstrak artefak browser dan buat timeline kegiatan.

Panduan Singkat Menyiapkan Lab Lokal

  1. Gunakan VirtualBox / VMware untuk VM offline. Alternatif: Docker untuk layanan (ELK, CTFd, DVWA).
  2. Contoh stack minimal: Kali (attacker), Ubuntu server (target), ELK stack (monitor).
  3. Amankan jaringan: gunakan jaringan internal / host-only, tidak terhubung ke internet kecuali diperlukan.

Contoh perintah Docker (ELK ringan)

docker run --name elastic -d -e "discovery.type=single-node" docker.elastic.co/elasticsearch/elasticsearch:8.8.0
# lalu jalankan logstash/kibana sesuai dokumentasi

(Ganti versi dengan yang tersedia; perintah di atas hanya contoh ringkas.)

Deploy Gratis (GitHub Pages — Langkah Lengkap)

1. Buat Repository

  1. Buka GitHub → klik New Repository.
  2. Nama repo bebas, misalnya cyberlab.
  3. Pilih public → Create Repository.

2. Upload File Website

  1. Buka repo → klik Add file → Upload files.
  2. Upload file index.html dari canvas ini (unduh dulu lalu upload).
  3. Commit changes.

3. Aktifkan GitHub Pages

  1. Buka tab Settings.
  2. Pilih menu Pages.
  3. Di bagian Source, pilih:
    • Branch: main
    • Folder: /root
  4. Klik Save.

Setelah 15–30 detik, situs muncul di URL GitHub Pages seperti:
https://username.github.io/cyberlab

4. (Opsional) Custom Domain

  1. Di Settings → Pages, masukkan domain.
  2. Tambahkan DNS CNAME ke username.github.io.
